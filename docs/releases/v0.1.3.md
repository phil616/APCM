## 更新内容

- 新增“AltasCI 证书管理”，支持独立签发端点、SAN-only CSR、幂等签发恢复、证书查询、导出、安装、吊销及续期提醒。
- 新增实例所有者管理：独立登录、CA 导入、完整策略编辑、Token 创建与撤销、证书历史分页。
- 支持为公开端点和管理端分别加载 PFX/PEM 通信 mTLS 身份，并分别配置 HTTPS 服务器信任根、业务证书信任根、代理及超时；缺少通信证书时给出明确提示。
- 移除旧“PKI 连接”和“AltasCI PKI”功能，保留本地证书、CNG 私钥和 CSR 管理。
- 修复发版流程：支持标签推送，核对标签与项目版本；已有标签但尚未创建 Release 时仍可发布。

## 升级与下载

- 安装包：`APCM-0.1.3-x64.msi`，适用于 Windows x64；附带 `.sha256` 校验文件。
- 保险库自动从架构版本 1/2 迁移到 3，保留原申请和审计记录。升级前建议备份原加密保险库；新架构不能直接由旧版程序打开。
- 通信 mTLS 证书与业务证书相互独立；重新解锁或切换连接后需重新加载通信身份。签发 Token 使用 Windows 凭据管理器保存。
- 续期创建新签发任务，不自动替换外部服务配置；生成的业务私钥保留在 CNG，默认不可导出。

详细使用说明见 [AltasCI 独立签发说明](https://github.com/phil616/APCM/blob/v0.1.3/docs/INDEPENDENT_SIGNING.md)。
