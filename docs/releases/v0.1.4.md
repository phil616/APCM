## 修复内容

- 修复“AltasCI 证书管理”中新建签发时的 CSR 兼容性错误：Windows CertEnroll 生成的 CSR 统一使用标准 `CERTIFICATE REQUEST` PEM 包装。
- 独立签发使用专用 CSR 配置，关闭 Windows 默认扩展，只请求 SAN；KU/EKU 继续由服务端策略决定。
- 修复 Windows BMPString 编码的中文 Subject 解码，避免组织等字段被错误读取。
- 导入 Windows 旧 `NEW CERTIFICATE REQUEST` 包装时，保留原始 DER 和签名，仅规范化 PEM 包装；含不支持扩展的外部 CSR 仍会被拒绝。
- 明确界面中的“本地生成 CSR 后签发”流程：私钥留在本机 CNG，通过 HTTP 提交公开 CSR 和有效期，通信 mTLS 身份保持独立。
